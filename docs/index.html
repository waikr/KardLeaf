为什么选择 KardLeaf

轻量，但不简单

卡叶笔记（KardLeaf）以真实 Markdown / TXT 文件为核心，让笔记数据保持开放、可迁移，也方便与 Obsidian 等工具配合使用。

01

本地文件优先

正文保存为真实的 Markdown / TXT 文件。备份、迁移、同步和跨应用编辑都更直接。

notes/├─ 灵感.md└─ 项目/计划.md
02

实时编辑与预览

常用 Markdown 格式、任务、图片、代码块和公式，写作与检查排版可以快速切换。

03

灵活分类整理

支持多级目录、顶部分类、侧边栏、标签和属性，让小记录与大型笔记库都井然有序。

04

兼容现有工作流

可以配合 Obsidian、VS Code、Typora、WebDAV 或 Syncthing 使用同一批文件。

05

隐私由你掌控

不强制注册账号，不强制上传云端。你可以自己决定笔记放在哪里、怎样同步。

界面预览

从文件保存、Obsidian 兼容到同步和隐私，先回答最常见的问题。更完整的下载安装、迁移、任务、AI、网页笔记与故障排查见完整 FAQ。

KardLeaf 和普通云笔记最大的区别是什么？

核心区别是本地文件优先：正文以真实 Markdown/TXT 文件保存，不需要先进入某个专有云格式。你可以直接备份、复制、同步，也能继续用 Obsidian、VS Code、Typora 等工具读取。

需要注册账号或联网才能记笔记吗？

不需要强制账号。普通本地创建、编辑、搜索和分类可以离线使用；只有 WebDAV/S3 同步、网页读取、AI 和版本检查等网络功能需要联网。

能直接配合 Obsidian 使用吗？

可以把普通 Markdown Vault 作为开放文件工作流使用，并保留目录、标签、YAML 属性和 [[Wikilink]] 等常用结构。KardLeaf 不是 Obsidian 官方客户端，也不承诺兼容全部桌面插件。了解兼容边界 →

支持哪些同步方式？

可以使用应用内 WebDAV、S3 兼容对象存储，也可以让 Syncthing 或其他文件同步工具负责整个笔记库。查看同步与备份 →

隐私笔记只是“隐藏”吗？

不是。隐私仓库使用独立加密流程；当前公开实现包含 PBKDF2-HMAC-SHA256、AES-GCM、HKDF-SHA256 和随机主密钥。查看加密实现 →

除了写 Markdown，还有任务和思维导图吗？

有。KardLeaf 提供独立任务清单与提醒，也能从 Markdown 标题生成思维导图，并用 Wikilink 生成笔记关系图。

可以把网页保存成笔记吗？

可以先在线读取并提取网页正文，需要编辑时再离线保存为 Markdown，还能选择下载网页图片。查看网页笔记 →

换手机或以后不用 KardLeaf，笔记怎么办？

正文就是普通 Markdown/TXT 文件，可以直接复制迁移；应用还提供 JSON 导出/导入与定期自动备份，降低被单一应用锁定的风险。
