KardLeaf Feature Guide

主题、侧边栏、工具栏与界面自定义

KardLeaf 把大量界面行为做成可配置项：应用主题、颜色、圆角、侧边栏样式、首页布局、卡片信息、工具栏顺序、编辑器字体、预览主题、隐藏文件规则和启动方式都可以调整。

主题与颜色

  • 亮暗模式：AppThemeMode 包含跟随系统、浅色、深色。
  • 主题风格：代码存在经典、圆润、Now in Android 风格、清爽列表，以及 Dracula、GitHub Dark 等专门样式引用。
  • 强调色：可选预设主题色，也可以输入自定义颜色。
  • 背景色：支持单独设置背景颜色和自定义值。
  • 圆角：存在全局圆角、首页圆角、任务圆角等参数，可以改变卡片/组件轮廓。
  • 应用语言：设置中维护应用语言，并为大量设置项提供中英文标签。

侧边栏自定义

DrawerStyle 目前定义四种主要侧边栏样式：MINIMAL_TEXT、ICON_BOX、GROUPED_CARD、DATA_CARD。

  • 功能项顺序：侧边栏项目顺序单独保存。
  • 隐藏功能：除必要项目外，可以把不常用入口隐藏。
  • 分组：支持设置分组起点，把大量功能拆成更清晰区域。
  • 自定义名称：每个 Drawer Item 可以保存自己的显示名称。
  • 头像与名称：侧边栏支持自定义头像 URI 和名称。
  • 边缘手势宽度：可以调整从屏幕边缘拖出侧栏的响应宽度。

首页布局与卡片内容

  • 布局模式：列表/多列等首页布局由设置管理。
  • 卡片密度：可以改变信息间距和卡片紧凑程度。
  • 排序：排序字段和升/降序均可配置，另有自定义排序和目录单独排序相关能力。
  • 显示信息：可以控制 YAML 标签、修改日期、笔记标题、日期文件名标题等是否出现在卡片上。
  • 图片预览：首页卡片可显示第一张图片缩略图。
  • 默认启动分类：决定打开应用时优先落到哪里。

多组可编辑工具栏

KardLeaf 不只允许改编辑器底栏。多个操作区域都有自己的顺序、隐藏和“更多”配置。

  • 首页底部工具栏：任务、新建笔记、速记、绘图、文件夹和各导航页面均可作为按钮；还可调按钮大小。
  • 长按选择栏：移动、复制、合并、置顶、收藏、标签、归档、属性、分享、隐私、删除可重新排列或隐藏。
  • 编辑器底部工具栏：29 个内置编辑项加上自定义功能项可以调整顺序。
  • 编辑器顶部工具栏：有独立 order / more / hidden 设置。
  • 文本选择工具栏：可以启用/关闭并控制布局与操作。

编辑器排版与行为

  • 字体大小：编辑器字号独立配置。
  • 行距 / 字距 / 段距：分别有 multiplier、letter spacing、paragraph spacing 参数。
  • 字体：可选内置字体系列，也支持填写自定义字体名称。
  • 打开笔记模式：可决定默认 Preview 还是编辑模式。
  • 编辑内核：可选 Auto、Native、CodeMirror Live Preview、Quillpad 风格等。
  • 编辑图片预览：存在独立开关，决定编辑过程中是否显示图片渲染。
  • 底部工具栏常驻：可控制编辑器底栏是否始终显示。

预览、侧栏与文件显示规则

  • Preview 主题：包含 Follow App、GitHub、Newsprint 等预览风格。
  • 双击间隔：预览交互的双击阈值可配置。
  • 笔记侧边面板：可以启用/关闭，并选择打开方式。
  • 隐藏文件夹：可指定目录不进入正常首页视图。
  • 隐藏文件名规则：支持用户自定义文件名匹配模式，控制哪些文件不作为普通笔记显示。
  • 废弃自动清理：Trash 自动清理天数可配置。

设置页自身也可搜索

设置项越来越多以后，KardLeaf 没有只依赖层层菜单。设置页构建了 SettingsSearchItem 索引，并支持通过下拉动作进入设置搜索。

  • 搜索标题、分区和附加关键词。
  • 命中后直接跳转到相应页面或设置弹窗。
  • 例如布局、主题、工具栏、更新、日志、同步等都可以进入搜索索引。
