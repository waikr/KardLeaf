隐私仓库、历史版本与备注

隐私笔记使用独立加密仓库，支持密码和生物识别快捷解锁；普通笔记还提供历史版本搜索、版本对比、恢复、清理，以及独立备注记录。

独立隐私仓库

隐私功能不是简单地把笔记在首页隐藏。当前实现会在笔记库中维护独立隐私仓库元数据和加密后的笔记文件，并在解锁时才把内容加载进内存。

  • 初始化：首次设置密码后创建隐私仓库和随机主密钥。
  • 锁定：锁定时清除已解锁主密钥与内存状态。
  • 修改密码：验证旧密码后重新封装主密钥，不需要把所有笔记永久绑定到旧密码。
  • 旧数据迁移：代码包含 legacy 隐私数据迁移流程。

加密实现

从公开代码可以确认，隐私仓库使用现代认证加密组合，而不是仅保存一个 SHA 哈希来“隐藏”数据。

部分实现
主密钥32 字节随机主密钥。
密码派生密码 KDF 使用基于 HMAC-SHA256 的 PBKDF2 流程，默认迭代数 600,000。
元数据封装用派生密码密钥通过 AES/GCM 包装主密钥。
单篇笔记通过 HKDF-SHA256 从主密钥和随机 salt 派生笔记密钥。
正文加密AES/GCM，保存随机 nonce、salt、tag 参数和 ciphertext。
这些是代码实现说明，不等同于第三方安全审计结论。

密码与生物识别解锁

  • 密码解锁：读取仓库元数据并验证/解包主密钥。
  • 生物识别快捷解锁：首次密码成功后可把主密钥通过 Android Keystore 中的密钥包装，再用于指纹/生物识别流程。
  • 密钥失效处理：当系统密钥不可用时，会提示重新使用隐私密码解锁。
  • 应用级安全设置：设置页还存在应用密码、指纹锁和密码输入模式等入口，和隐私仓库本身是不同层面的保护。

历史版本

  • 版本列表：每篇笔记可以读取保存过的历史版本，并显示保存时间和内容预览。
  • 搜索旧版本：历史存储支持关键词查询，并限制返回数量以控制内存。
  • 版本比较：历史对话框允许选择左右两个版本，构建差异模型查看内容变化。
  • 恢复：选中旧版本后可以恢复为当前内容。
  • 删除：单个历史版本可以删除。
  • 保留数量：设置中可以配置版本上限，并预览清理将删除多少旧版本。

笔记备注

备注不是硬塞进正文末尾。NoteRemarkEntity 单独保存笔记 ID、备注内容、创建时间和更新时间，编辑器属性/侧边面板会加载对应备注。

  • 可以给正文添加额外说明，不破坏 Markdown 内容。
  • 备注有独立创建和更新时间，适合记录修订意见或后续想法。
  • 设置页存在备注记录管理入口，可以从记录汇总回到原笔记。
