Markdown 编辑器与实时预览

KardLeaf 提供多种编辑内核、丰富的 Markdown 工具栏、实时预览、文章目录、Wikilink、表格、数学公式、代码块、Mermaid 与可自定义编辑命令。

多编辑内核

KardLeaf 把“笔记文件”和“编辑体验”分开处理，因此同一批 Markdown 文件可以使用不同编辑内核打开。当前代码中的 EditorKernel 包含自动、Native、CodeMirror 实时预览与 Quillpad 风格内核。

  • Native Alpha：偏原生 Android 的文本输入与编辑实现。
  • Native Beta / Quillpad 风格：强调原生输入、光标与选择体验，同时文件、笔记库、历史、图片和管理逻辑仍由 KardLeaf 负责。
  • WebView / CodeMirror：普通笔记可使用 CodeMirror 6 编辑器，承担丰富 Markdown 交互和实时渲染能力。
  • 自动选择：设置中存在自动内核模式，应用可根据配置选择编辑实现。

Markdown 与扩展语法

除了基础 Markdown，CodeMirror 编辑器代码中已经接入多个块级和交互插件，让手机端可以直接处理更复杂的文档。

  • 表格：表格插件负责块表格渲染，并配套表格操作入口。
  • 数学公式：编辑与预览链路包含数学插件，预览资源使用 KaTeX/TeX 相关渲染。
  • 代码块：支持块级代码显示，并包含源码/渲染状态相关逻辑。
  • Mermaid：代码中提供 Mermaid 渲染、缓存和放大查看事件。
  • Admonition：编辑器插件提供提示块/警告块类型支持。
  • HTML：存在 raw HTML 渲染扩展，用于识别和显示 HTMLBlock / HTMLTag。
  • 块图片：编辑器对 Markdown 图片提供块级渲染、选中状态和相关交互。
  • Wikilink：支持 [[笔记]] 类型链接；显示态可像普通链接一样打开，编辑态仍可修改目标文本。
  • 斜杠命令：输入 / 后由 slash command 插件提供候选项，表格、公式、Mermaid、代码块、图片等插件可以注册命令。

编辑、预览与长文导航

  • 编辑 / Preview：可在编辑和预览之间切换，也能设置打开笔记时优先进入预览或编辑。
  • 独立预览控制器：预览使用专门 WebView 控制器，加载 Markdown 渲染资源并处理本地图片。
  • 文章目录：编辑器侧边面板提供文章目录/大纲，用标题结构快速定位长文。
  • 查找：编辑器与全局搜索逻辑分开，编辑场景支持在当前文档内定位文本。
  • 预览主题：设置中存在 Follow App、GitHub、Newsprint 等预览主题，用于改变 Markdown 阅读排版。
  • 字体与排版：编辑器代码支持字体、字号、行距等编辑显示参数同步到内核。

快捷文本与自定义命令

KardLeaf 允许把重复输入内容做成自己的编辑命令。

  • 快捷文本：可保存一组常用片段，内置数据结构限制为最多 24 项；每项包含名称和要插入的文本内容。
  • 自定义符号：可维护自定义符号列表，适合经常输入的特殊字符、标记或短文本。
  • 自定义功能项：支持名称、SVG 图标与插入内容，生成稳定 ID 后可与内置工具一起排列。
  • 工具栏排序：编辑器工具栏不是写死顺序，可以按自己的使用频率调整。
  • 文本选择工具栏：代码中存在 1/2 行布局和命令配置，可改变选中文本后显示的操作集合。

属性、统计、链接与备注侧栏

  • YAML / Front Matter：编辑器属性面板会解析 Front Matter 属性，并保留 Markdown 文件中的元数据。
  • 文字统计：可读取字符数、含标点词数、不含标点词数、行数和段落数。
  • 链接关系：编辑侧栏能接收笔记链接实体，用于查看当前笔记的链接关系。
  • 备注记录：备注与正文分开维护，记录创建/更新时间，可作为对正文的补充说明。
  • 历史版本：编辑器可进入历史列表、搜索历史内容、比较两个版本并恢复旧版本。
