Markdown 思维导图

把 Markdown 标题层级直接转成可交互思维导图，并支持节点新增、重命名、删除、拖拽移动、撤销恢复、单双向布局、大纲定位和主题切换。

从 Markdown 结构生成导图

思维导图不是另一套封闭数据。KardLeaf 会解析笔记中的标题层级，把标题树转换成 MindMapDocument。中心主题和子节点仍然对应 Markdown 内容，因此导图编辑最终回写到文档结构。

  • 中心主题：可从根标题创建中心节点。
  • 层级关系：标题深度映射为父子节点关系。
  • 继续作为 Markdown：退出导图后内容仍然是可被其他编辑器读取的普通 Markdown。

节点编辑

  • 新增子节点：对选中节点继续向下扩展内容。
  • 新增同级节点：在当前层级插入并列主题。
  • 修改标题：节点标题可直接编辑，随后更新 Markdown 对应标题。
  • 删除节点：提供节点删除操作，并由编辑动作重新生成文档结果。
  • 拖拽移动：onNodeMove 接收移动节点、目标父级和目标子位置，可跨父级改变层级，也可在同级中重新排序。

单向 / 双向布局

导图工具栏提供布局切换。当前代码明确维护“单向”和“双向”两种状态，并根据当前模式改变按钮提示。

  • 单向布局：子节点集中向一侧展开，适合线性层级。
  • 双向布局：从中心主题向左右两侧分配分支，适合节点较多的主题。
  • 连线与位置：布局引擎根据节点树计算位置和连线，移动节点后会重新形成结构。

缩放、平移与大纲

  • 缩放反馈：导图页面维护缩放比例并显示百分比提示。
  • 画布平移：导图采用独立舞台处理触摸移动，方便浏览超出屏幕的节点。
  • 大纲侧栏：showOutline 控制大纲显示，当前选中节点与大纲选择状态可以联动。
  • 长文定位：比起在大画布上逐个寻找节点，可以从大纲快速定位结构。

撤销、恢复与主题

  • 撤销 / 恢复：工具栏有独立 Undo、Redo 按钮，适合连续调整节点结构。
  • 节点主题：导图提供主题菜单，可改变节点视觉主题。
  • 与编辑器联动：导图编辑结果仍由编辑器动作处理，因此不会形成与正文脱节的第二份笔记。
