KardLeaf Feature Guide

笔记、文件夹、标签与本地文件管理

KardLeaf 以真实 Markdown/TXT 文件为核心，提供多笔记库、多级文件夹、标签、收藏、置顶、速记、归档、废弃、日期入口、批量操作和可自定义侧边栏。

真实文件与多笔记库

KardLeaf 的正文不是只存在数据库记录里，而是保存为普通的 .md / .txt 文件。Room 主要承担索引、缓存和状态管理，因此同一批文件仍能被其他 Markdown 工具读取。

  • 用户选择目录：通过 Android 存储访问机制使用普通目录作为笔记库。
  • 多笔记库入口：侧边栏代码提供新增、切换、重命名、删除笔记库的回调，可把工作、学习、私人资料分开。
  • 外部修改刷新：其他工具修改 Markdown 文件后，KardLeaf 可以重新读取和刷新索引。
  • 开放迁移：文件本身保持 Markdown/TXT，可直接复制、备份或交给 Obsidian、VS Code、Typora 等使用。

多级文件夹与目录树

  • 多级目录：文件夹可以嵌套，不局限于一级分类。
  • 展开 / 折叠：侧边栏文件树保存折叠状态，并支持全部展开、全部折叠。
  • 创建与重命名：可以从目录结构中创建文件夹、创建笔记，并在重命名后同步更新树路径状态。
  • 移动笔记：移动操作选择目标文件夹；在相对图片模式下，仓库代码会考虑重写相对图片引用。
  • 自定义排序：文件夹显示顺序可以保存，适合按自己的工作流排列常用目录。
  • 隐藏目录：主视图可以排除隐藏文件夹，同时保留包含隐藏项的完整数据源供管理场景使用。

首页分类与常用视图

侧边栏和首页不是只有“全部笔记”，代码中已经定义了多个独立入口。

入口作用
全部笔记显示当前笔记库中正常状态的笔记。
最近修改按最近修改维度快速回到刚处理的内容。
收藏集中查看标记为 Favorite 的笔记。
速记独立 Quick Notes / Drafts 入口，适合快速捕捉。
随机随机抽取笔记，适合回顾旧内容。
日期按日、周、月浏览笔记。
图片从笔记中汇总本地图片引用形成图库。
关系进入笔记双向链接或自定义知识关系图。
归档把暂时不参与日常列表的内容单独保留。
废弃进入 Trash 状态，支持后续清理逻辑。
隐私进入独立的加密隐私仓库。

标签与 YAML 属性

  • #标签：索引层会读取 Markdown 中的标签，用于分类和筛选。
  • YAML tags：Front Matter 中的标签单独写入索引字段，便于与 Obsidian 风格属性协作。
  • 标签管理页：项目存在独立 TagManagementScreen，可浏览标签并进入对应笔记。
  • 标签筛选：全局搜索选项也支持指定 tag，因此标签既是导航维度，也是搜索条件。
  • 属性面板：编辑器能够解析并显示 Front Matter 属性，而不是把 YAML 当作普通正文。

单篇与批量操作

长按选择栏当前定义了 11 类主要操作，并允许调整顺序与隐藏项目。

  • 移动：把一篇或多篇笔记移动到目标文件夹。
  • 复制：在目标目录生成副本。
  • 合并：把多篇选中内容合并处理。
  • 置顶 / 收藏：改变首页优先展示和收藏状态。
  • 标签：批量处理笔记标签。
  • 归档：批量进入归档状态。
  • 属性：打开笔记属性信息和统计。
  • 分享：调用 Android 分享流程。
  • 隐私：把内容移入隐私相关流程。
  • 删除：进入废弃/删除逻辑。

首页布局与缩略图

  • 列表 / 多列：设置中明确提供布局模式选择。
  • 卡片密度：可在宽松和紧凑等密度间调整。
  • 排序：支持排序字段、升序/降序，以及自定义排序相关逻辑。
  • 图片缩略图：索引保存每篇笔记第一张本地图片引用，首页卡片优先从缓存显示首图。
  • 底部工具栏：首页可使用简洁新建按钮或底部工具栏；可放任务、新建笔记、速记、绘图、新建文件夹以及各类导航入口。
  • 默认启动分类：设置里可以决定进入应用后默认打开的分类/目录。
