网页笔记与外部调用

KardLeaf 可以直接读取网页、提取正文并在 Preview 中在线阅读；需要编辑时再离线保存，还可以选择下载网页图片。自定义 URL Scheme 让浏览器、Tasker 与其他应用直接新建笔记。

在线阅读网页

网页笔记流程不是一开始就把整个网页和图片全部下载。当前界面明确提供“在线阅读网页”模式：先从 http/https 地址读取页面、提取正文，再直接在 KardLeaf 的 Preview 中只读显示。

  • 只接受网页地址：保存入口会验证当前页面是有效的 HTTP/HTTPS URL。
  • 正文提取：项目依赖 Readability4J Extended，从复杂网页中提取主要阅读内容。
  • HTML 转 Markdown：项目同时引入 Flexmark HTML-to-Markdown converter，便于把提取后的网页内容转换为可保存文本。
  • 先读后存：在线阅读阶段不强制下载图片，减少无用文件和等待。

离线并编辑

当用户决定真正修改网页笔记时，可以执行“离线并编辑”。这时网页内容会进入本地 Markdown 工作流，不再只是一个在线只读页面。

  • 将提取后的正文作为笔记内容保存。
  • 可指定目标文件夹，保持与普通本地笔记一致的目录管理。
  • 保存后可以继续使用编辑器、历史版本、标签、搜索等普通笔记能力。
  • 如果页面无法读取或不是支持的网页地址，会返回明确错误信息。

网页图片本地化

网页导入对图片提供独立开关“离线时下载网页图片”。

  • 关闭：在线阅读时不下载图片，优先快速查看正文。
  • 开启：点击“离线并编辑”时，把可下载图片保存到 KardLeaf 本地图片目录。
  • 替换引用：导入流程会取得本地图片引用，再写入生成的 Markdown，减少离线后图片失效。
  • 失败容错：单个图片无法导入时不会要求整个网页导入流程完全失败。

kardleaf:// 外部新建笔记

KardLeaf 提供自定义 URL Scheme，可以从浏览器、自动化软件、快捷方式或其他 Android 应用直接打开新建笔记界面。

kardleaf://new?title=标题&content=正文&url=网页地址&path=资料/网页收藏&pinned=1&root=0
参数作用
title预填笔记标题。
content预填正文，也兼容 body / text 别名。
url把网页地址带入正文。
path指定保存目录，也兼容 folder / label。
pinned决定新建后是否置顶。
root控制目标路径的解释方式。

适合的自动化场景

  • 浏览器收藏：把当前网页标题和 URL 传给 KardLeaf，快速生成待整理笔记。
  • Tasker / 自动化脚本：用 Scheme 预填固定目录和正文模板。
  • 桌面快捷方式：创建直接进入特定新建流程的入口。
  • 其他应用分享：KardLeaf 还包含分享接收与速记流程，可把 Android 分享内容转进笔记。

继续了解

Markdown 编辑器离线后继续编辑网页 Markdown。图片与绘图了解本地图片保存和查看。快捷记录查看桌面与分享入口。
