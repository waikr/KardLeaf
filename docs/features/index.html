功能模块

KardLeaf 不只是一个 Markdown 输入框。它围绕“真实文件 + 移动端编辑 + 知识整理 + 可迁移数据”构建了一整套功能。下面每个模块都有独立子页面，便于搜索引擎和用户直接找到需要的能力。

核心笔记能力

  • 真实 Markdown / TXT 文件：正文保存在用户选择的本地目录中，不把正文锁死在应用私有数据库里。
  • 多笔记库：代码中提供笔记库新增、切换、重命名与删除入口，可按不同项目或用途分开管理。
  • 目录与标签：多级文件夹、目录树、YAML 标签、普通标签视图、收藏、置顶、归档、废弃、速记和随机笔记入口。
  • 首页组织：列表/多列布局、卡片密度、图片缩略图、排序、分类切换、底部工具栏和长按批量选择栏。
  • 批量操作：移动、复制、合并、置顶、收藏、标签、归档、属性、分享、隐私和删除等操作可进入选择工具栏。
  • 日期视图：按今天、周、月查看笔记，并支持月份切换和日期定位。
  • 文字统计：属性面板可统计字符数、含标点词数、不含标点词数、行数、段落数等。
  • 侧边栏热力图：代码中存在独立热力图统计与按天数据，用于展示笔记活动和文字统计趋势。

编辑与知识表达

  • 多编辑内核：原生编辑、Native Beta/Quillpad 风格输入体验，以及 WebView / CodeMirror 实时预览内核。
  • 29 个内置编辑工具：预览、撤销/恢复、图片、附件、绘图、日期时间、快捷文本、标题、分割线、粗体、斜体、下划线、删除线、高亮、链接、行内代码、代码块、引用、公式、列表、缩进、任务和表格等。
  • 扩展 Markdown：CodeMirror 代码模块包含表格、数学公式、Mermaid、admonition、HTML、块图片、智能粘贴、斜杠命令和 Wikilink。
  • 文章目录：编辑器提供大纲/目录面板，可用于长文档定位。
  • 双向链接：识别 [[笔记]] 链接，并把笔记之间的链接关系用于关系图。
  • 备注与历史：单篇笔记可维护备注记录，也可以查看、搜索、比较和恢复历史版本。

任务、思维导图与知识关系

  • 任务清单：独立任务支持分组、子任务、优先级、到期时间、提醒时间、重复、备注、手动排序与废弃。
  • Markdown 任务：可以扫描 Markdown 中的任务并合并显示，解析优先级、重复、日期等任务元信息。
  • 提醒：支持弹窗或通知方式，可控制铃声与振动，并包含开机后重新调度逻辑。
  • 思维导图：从 Markdown 标题层级构建，可新增子节点/同级节点、改名、删除、移动、撤销恢复、切换单双向布局和打开大纲。
  • 笔记关系图：读取现有笔记与双向链接建立自动关系图，可搜索、缩放、适配全图并调节力导向显示参数。
  • 自定义关系图：不依赖笔记链接，也能自行创建关系图、节点和连线，并进行编辑和持久化保存。

图片、网页、同步与数据安全

  • 图片：编辑态/预览态图片、本地图片引用、首页首图缩略图、图片图库、缩放平移查看。
  • 绘图与标注：画笔、荧光笔、区域橡皮、整笔擦除，支持方格/横线/点阵画布、颜色与粗细设置、撤销恢复和图片标注。
  • 网页笔记：在线阅读网页，提取正文后在 Preview 中只读显示，需要编辑时可离线保存，并可选择把网页图片下载到本地。
  • WebDAV：应用内云同步，包含远端检查、同步预览、冲突处理相关界面和实时同步选项。
  • S3 兼容同步：代码中包含 S3 客户端、签名、设置页、同步计划与恢复副本机制，可用于 S3 兼容对象存储。
  • 备份：支持数据 JSON 导入/导出以及按周期自动写入指定目录。
  • 隐私仓库：隐私笔记使用加密仓库保存，支持密码和生物识别快捷解锁；另有应用密码/指纹锁入口。

桌面入口与自动化

  • 桌面小部件：代码中存在笔记列表、任务清单、每日笔记与快速笔记小部件，并提供主题与文件夹等配置。
  • 快捷设置磁贴：提供 Quick Add 与 Quick Memo 的 Android 快捷设置入口。
  • 分享与速记：支持从其他应用分享内容进入速记流程。
  • 自定义 URL Scheme：kardleaf://new 可接收标题、正文、网页地址、目录和置顶参数，便于浏览器、Tasker 或自动化脚本调用。
  • 可重排功能项：侧边栏、首页底部工具栏、长按选择栏以及编辑器工具栏都存在顺序/显示项配置。
这里描述的是当前公开仓库中能够直接从实现、设置项或界面入口确认的能力；实验性功能会随版本继续调整。
