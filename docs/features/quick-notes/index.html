速记、分享捕捉与快速新建

KardLeaf 有独立“速记 / Quick Notes”筛选与默认速记目录，并提供首页新建速记、快捷设置磁贴、分享接收、桌面快捷方式和 Widget 快速新建，让临时想法先快速落盘再整理。

独立速记视图

MainViewModel.NoteFilter.QuickNotes 是独立筛选类型，并对应侧边栏中的 DRAFTS / “速记”功能项。

  • 默认速记目录：Quick Notes 会读取默认速记文件夹中的笔记。
  • 首页入口：首页底部工具栏也可以直接放“速记”。
  • 专用显示：速记卡片可以和普通笔记采用稍有区别的标题展示逻辑，减少临时记录的视觉负担。

首页快速新建速记

在速记筛选页中，首页 FAB 会走专用 quick memo 创建路径；首页快速创建菜单也包含“新建速记”。

  • 不需要先选择目录。
  • 直接使用当前选定编辑内核进入记录。
  • 保存后仍是普通本地笔记，可以稍后移动到正式目录。

从其他应用分享到速记

ShareToQuickMemoActivity 是专门的 Android 分享接收入口。它会限制过长的分享标题和正文，避免异常应用一次塞入无限内容。

  • 标题上限：当前代码限制分享标题最多 120 字符。
  • 正文上限：分享正文最多 50,000 字符。
  • 适合网页/文本：浏览器、聊天工具、阅读器中选中文本后可以直接分享进速记。

快捷设置 Quick Memo

QuickMemoTileService 可以加入 Android 下拉快捷设置区域。设备锁定时，代码会根据锁屏安全状态决定先解锁再进入速记。

  • 下拉通知栏即可启动。
  • 无需先回桌面找到 App 图标。
  • 适合临时想法、电话号码、会议要点等极短路径记录。

桌面快速新建

NoteWidgetQuickAddActivity 支持目标目录、初始标题和内容等参数；当目标文件夹是默认速记目录时，界面标题会显示“新建速记”。

  • 可从桌面 Widget 直接新建。
  • 保存后会刷新笔记列表和每日笔记等相关 Widget。
  • WidgetPinHelper 也可以固定 Quick Memo 快捷方式。

继续了解

桌面与快捷入口查看全部 Widget 和 Tile。网页笔记长网页可走网页正文提取。笔记管理速记完成后可移动、标签和归档。
