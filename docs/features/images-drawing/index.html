KardLeaf Feature Guide

图片、图库、绘图与图片标注

KardLeaf 支持本地图片引用、首页缩略图、图片图库、缩放查看，也内置画笔、荧光笔、两种橡皮、网格画布、撤销恢复以及在原图上进行标注。

笔记中的图片

  • 本地图片引用：仓库会从正文提取图片引用，并根据根目录/相对路径模式解析资源。
  • 编辑态图片：CodeMirror 编辑器包含块图片插件，用于在编辑时渲染图片并维护选中状态。
  • 预览态图片：Markdown Preview 会通过本地资源解析器加载图片。
  • 首页首图：索引字段 firstImageReference 保存第一张图片引用，让首页卡片不用每次读取全文就能显示缩略图。

图片图库

侧边栏“图片”进入独立图库页面。页面会先使用笔记元数据里已经索引的第一张图片快速出结果，再逐步扫描更多本地 Markdown 图片引用，避免为了打开图库一次性阻塞读取全部正文。

  • 只统计正常笔记，不把废弃内容混入主图库。
  • 图片卡片关联来源笔记，可以从图片回到对应内容。
  • 本地资源支持普通文件引用以及应用能解析的数据形式。

图片查看器

  • 双指缩放：图片查看器使用 transform gesture，根据手势中心调整缩放。
  • 平移：放大后可以拖动画布查看细节。
  • 缩放边界：缩放比例会限制在合理范围，避免无限放大导致交互失控。
  • 适配屏幕：初始状态根据源图尺寸和视口计算 Fit Center 变换。

内置绘图

绘图模块使用独立画布，并把视觉结果与可恢复的 drawing source 一起保存。

类别能力
工具画笔、荧光笔、区域橡皮、整笔擦除。
背景空白、方格、横线、点阵。
外观画布颜色、画笔颜色、荧光笔颜色。
粗细画笔、荧光笔、橡皮分别维护笔触宽度。
历史撤销、恢复、清空。
保存导出 Bitmap，同时保存可再次编辑的绘图源数据。

图片标注

绘图页接收 initialBackgroundBitmap 时会进入“图片标注”状态，把原图作为画布背景。它同时保留源图宽高、MIME 类型和 EXIF 方向信息，便于在正确坐标系中叠加笔迹。

这意味着绘图和图片标注共用一套工具：你可以先打开图片，再用画笔/荧光笔/橡皮进行说明，之后保存为带标注的结果。

图片路径与移动笔记

  • 根目录路径：ImagePathMode.ROOT 使用相对笔记库根目录的引用策略。
  • 相对路径：ImagePathMode.RELATIVE 支持相对当前笔记位置引用。
  • 相对图片位置：可选择当前笔记文件夹或固定图片目录。
  • 移动时处理：仓库移动笔记时包含重写相对图片引用的逻辑，降低移动文件后图片失联的概率。
