任务清单、Markdown 任务与提醒

KardLeaf 内置独立任务系统，并能把 Markdown 待办纳入任务视图；支持分组、子任务、优先级、到期时间、重复、备注、搜索、排序、废弃和多种提醒方式。

任务可以保存哪些信息

任务实体不是只有“文字 + 完成状态”，当前数据结构包含一整套任务字段。

  • 任务正文：taskText 保存任务内容，done 表示完成状态。
  • 分组：groupId 对应任务分组，分组本身也有名称和排序。
  • 层级：parentTaskId 用于父子任务关系，编辑结果还支持一次带入子任务文本。
  • 优先级：priority 用于任务优先级排序。
  • 时间：dueAt 表示到期时间，reminderAt 表示提醒时间。
  • 重复：repeatRule 保存重复规则。
  • 备注：notes 作为任务附加说明。
  • 提醒方式：支持 POPUP 与 NOTIFICATION，并可分别控制铃声和振动。
  • 手动顺序与废弃：manualOrder 用于拖动排序，isTrashed 保存废弃状态。

Markdown 任务开关可决定是否把从笔记扫描到的 Markdown 任务合并显示。

重复任务

内置重复规则包含“不重复、每天、每周、每月”。完成一个重复任务时，代码会计算下一次发生时间；如果原时间已经过期，会继续向后推进，直到下一次时间晚于当前完成时刻，避免生成一个立刻过期的新任务。

  • 每天：基于日历增加一天。
  • 每周：增加一周。
  • 每月：按日历月份推进。
  • 到期时间和提醒时间会分别向下一周期推进。

提醒与系统权限

  • 弹窗提醒：任务可以使用独立提醒页面，代码包含锁屏显示和点亮屏幕相关处理。
  • 通知提醒：也可以只使用 Android 通知渠道。
  • 铃声 / 振动：任务级字段控制是否响铃、是否振动。
  • 精确提醒：设置界面会检查设备是否允许精确闹钟，并给出权限提示。
  • 开机恢复：存在 TaskBootReceiver，用于设备启动后重新处理任务提醒调度。
  • 测试提醒：代码中提供测试提醒延迟，用于验证权限和提醒链路。

Markdown 任务兼容

KardLeaf 会扫描 Markdown 待办，并解析一部分常见任务元信息。解析器可以识别任务状态以及额外的优先级、重复和日期类标记。

  • 优先级标记：解析器识别 🔺、⏫、🔼、🔽、⏬ 等优先级符号。
  • 重复：识别 🔁 后的重复描述。
  • 任务 ID：识别 🆔 标识，便于保持任务身份。
  • 日期元信息：解析器还处理创建、开始、计划、到期、完成等任务日期标记。
  • 可返回来源笔记：Markdown 任务保留来源文件路径，任务页可打开对应笔记。

任务数据与桌面入口

  • 任务数据位置：设置中提供任务清单数据位置，可指定管理任务 Markdown 文件所在目录。
  • 任务小部件：桌面可以添加 TaskListWidget，并从桌面查看或进入任务。
  • 首页入口：任务是首页底部工具栏和侧边栏都可以放置的独立功能项。
  • 任务废弃：任务页底部工具栏有废弃入口，任务实体保留 isTrashed 状态。
