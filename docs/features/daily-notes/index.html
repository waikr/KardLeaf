每日笔记与日期型记录

KardLeaf 提供每日笔记桌面小部件和独立目录设置，以 yyyy-MM-dd 作为每日文件名核心规则，适合日记、工作日志、学习记录和持续性记录工作流。

每日笔记命名规则

DailyNoteSupport 把当天日期转换成稳定标题，并使用 yyyy-MM-dd 作为文件日期格式。这样每天的笔记天然具备可排序、可搜索、跨工具通用的文件名。

Daily/Journal/2026-09-18.md
  • 按日期唯一：同一天会定位到同一个目标文件。
  • 自然排序：ISO 风格日期文件名按字符串排序时也保持时间顺序。
  • 普通 Markdown：每日笔记仍然是普通 .md 文件，不需要专有数据库格式。

每日笔记目录

每日笔记目录由偏好设置单独保存，getDailyNoteFolder() 会标准化路径，Widget 配置页也提供目录选择状态。

  • 可以把日记放在单独的 Daily、Journal、日志等目录。
  • 支持多级目录，例如 Daily/Journal。
  • 切换笔记库后，每日笔记仍按当前 Vault 的目录规则工作。

每日笔记桌面小部件

DailyNoteWidgetProvider 在桌面直接计算今天的标题和目标路径。如果笔记已存在就打开；不存在时可以进入创建流程。

  • 无需先打开首页：从桌面直接进入今天的记录。
  • 跟随目录设置：Widget 使用每日笔记专用文件夹配置。
  • 自动刷新：应用保存笔记或生命周期变化时，会触发每日笔记 Widget 刷新。
  • 可固定到桌面：WidgetPinHelper 提供每日笔记小部件固定入口。

适合哪些使用方式

  • 日记：每天一篇，不需要手工输入日期文件名。
  • 工作日志：记录当天完成事项、问题和明日计划。
  • 学习记录：按天积累课程、阅读和复习笔记。
  • Obsidian Daily Notes 工作流：因为最终是普通 Markdown 日期文件，可以继续由电脑端工具读取。
