笔记关系图与自定义知识关系图

KardLeaf 可以读取笔记和 [[双向链接]] 自动生成关系图，也可以完全手动创建自己的图、节点与连线，并提供搜索、缩放、全图适配和力导向参数调整。

自动笔记关系图

关系图会从正常状态笔记和链接索引生成图数据。代码会过滤废弃笔记，并读取已有 NoteLinkEntity，将笔记转换为节点、链接转换为边。

  • Wikilink 来源：界面空状态直接说明关系图读取现有笔记和 [[双向链接]]。
  • 点击节点：笔记节点保留对应笔记，可从关系图回到正文。
  • 孤立节点：设置项 showOrphans 决定是否展示没有连线的笔记。
  • 方向箭头：showArrows 控制边的方向提示。

自定义知识关系图

除了根据笔记自动生成，关系页还有 CUSTOM 模式。它维护独立的 CustomRelationshipGraph 列表，并把图结构持久化保存。

  • 新建、重命名、删除多个自定义关系图。
  • 添加和编辑节点，节点包含标题、副标题、分组和可选颜色。
  • 创建节点之间的关系，可保存边标签及方向性。
  • 进入自定义编辑模式后可管理节点与连线，而不是只能查看。

搜索、切换与全图适配

  • 节点搜索：顶栏提供搜索入口，通过关键词筛选节点。
  • 关系图切换：底部工具栏可在自动笔记图与自定义图之间切换。
  • 适配全图：Fit 操作用于把当前图重新缩放到合适视野。
  • 选择状态：自定义图会维护选中节点，用于进一步添加关系或编辑。

显示与力导向参数

关系图设置不是只有一个缩放开关。当前 RelationshipGraphSettings 暴露多组图形参数。

参数作用
nodeScale节点整体尺寸。
linkScale连线视觉尺度。
labelFade标签淡化程度。
centerForce向中心聚拢的力度。
repelForce节点之间的排斥力度。
linkForce连线约束力度。
linkDistance关系边目标距离。
