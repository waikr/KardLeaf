桌面小部件、快捷设置与快速记录

KardLeaf 提供笔记列表、任务清单、每日笔记和快速记录等桌面入口，并包含 Android 快捷设置磁贴、分享接收与固定快捷方式，让记录不必每次先进入应用首页。

桌面小部件

代码中存在多个独立 Widget Provider，不是把同一个小部件换名字。

小部件用途
NoteListWidget在桌面显示指定范围的笔记列表，并进入对应笔记。
TaskListWidget在桌面显示任务清单和相关任务入口。
DailyNoteWidget快速打开/创建当日笔记，日期格式由 DailyNoteSupport 管理。
QuickNoteWidget从桌面直接进入快速笔记/速记流程。

小部件配置

  • 目标文件夹：笔记类小部件可保存目标目录，让快速新建直接落到指定位置。
  • 独立设置界面：代码按 NOTE / TASK / DAILY 等 Kind 显示不同配置标题。
  • 小部件主题：WidgetTheme 提供预设，例如默认主题、深夜墨黑、纸张暖白、森林绿等。
  • 适应桌面：小部件有独立颜色/主题逻辑，不要求完全复制应用内当前页面。

Android 快捷设置磁贴

项目包含两个 TileService：

  • QuickAddTileService：从通知栏快捷设置区域进入快速新增流程。
  • QuickMemoTileService：直接打开“添加速记”，适合锁屏后下拉控制中心快速捕捉。

它们的价值在于减少“打开 App → 找到分类 → 点新增”的步骤。

固定快捷方式

WidgetPinHelper 负责请求把部分入口固定到桌面。当前项目包含任务、笔记、每日笔记和快速速记等快捷入口支持。

  • 可以把经常访问的功能放到桌面，而不是每次寻找侧边栏。
  • 如果桌面启动器不支持固定快捷方式，应用会给出失败提示。
  • 快捷方式和 Widget 是两套机制：前者更像“一个按钮”，后者可以直接展示内容。

分享接收与快速笔记

  • ShareReceiveActivity：接收其他 Android 应用分享来的文本/链接。
  • QuickNoteActivity：提供独立快速笔记入口。
  • NoteWidgetQuickAddActivity：从 Widget 接收目标目录、初始标题等参数，直接进入快速新增。
  • 与普通笔记统一：快速创建的结果最终仍进入 KardLeaf 的文件与笔记管理体系。

继续了解
