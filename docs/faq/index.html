下载安装与基本使用

适合第一次了解、下载或安装 KardLeaf 的用户。

卡叶笔记（KardLeaf）是什么？

卡叶笔记（英文名 KardLeaf）是一款面向 Android 的本地优先 Markdown 笔记应用。它以真实 .md / .txt 文件为核心，提供编辑、预览、文件夹、标签、搜索、任务、思维导图、知识关系、同步、隐私仓库等能力。

KardLeaf 适合哪些用户？

适合希望笔记文件掌握在自己手里、需要 Android Markdown 编辑、使用 Obsidian/Typora/VS Code 工作流、想通过 WebDAV/S3/Syncthing 自己控制同步，或不希望被单一云笔记格式锁定的用户。

KardLeaf 是免费的吗？

项目当前以开源方式发布，官网直接提供 APK 下载入口，源码采用 Apache License 2.0。具体版本、发布包和变更请以 GitHub Releases 为准。

KardLeaf 是开源软件吗？

是。源码公开在 GitHub，许可证为 Apache License 2.0，可在许可证允许的范围内查看、修改和分发代码。

KardLeaf 支持哪些系统？

当前公开版本面向 Android 6.0+。官网与仓库说明均以 Android 为主要平台。

KardLeaf 有 iOS、Windows 或 macOS 版本吗？

当前官网定位是 Android 应用。电脑端可以继续使用 Obsidian、VS Code、Typora 等工具打开同一批 Markdown 文件，再通过同步方案与手机协作。

KardLeaf 应该从哪里下载？

推荐从官网的“下载 APK”按钮或 GitHub Releases 最新版本下载，避免来源不明的二次打包 APK。

安装 APK 时 Android 提示“禁止安装未知应用”怎么办？

这是 Android 对浏览器/文件管理器侧载 APK 的系统保护。你需要在系统设置中临时允许当前下载来源安装应用；安装完成后可以再关闭该权限。

KardLeaf 需要注册账号吗？

不需要强制注册账号。普通本地笔记可以直接使用；只有你主动启用 WebDAV、S3、AI 等网络功能时，才需要填写相应服务的配置。

没有网络还能使用 KardLeaf 吗？

可以。普通本地笔记的创建、编辑、搜索、分类、历史版本等核心能力不依赖互联网。网页读取、云同步、AI 请求和版本检查等网络功能需要联网。

KardLeaf 会自动更新吗？

应用内包含版本检查逻辑，可以查询 GitHub Releases 的最新版本并提示更新；实际安装仍以你下载并安装新的 APK 为准。详见 版本更新检查。

如何确认自己安装的是最新版？

可以在应用设置中手动检查更新，也可以直接查看 最新 Release 的版本号和发布时间。

文件、数据与迁移

关于笔记保存位置、文件格式、导入现有笔记库和换设备。

KardLeaf 的笔记保存在哪里？

笔记正文保存在你授权给应用的普通目录中，并以真实 Markdown/TXT 文件存在。应用数据库主要承担索引、缓存和状态管理，而不是把正文锁进专有数据库。详见 本地文件管理。

KardLeaf 使用什么文件格式？

正文核心格式是 .md 和 .txt。Markdown 文件可以继续被 Obsidian、VS Code、Typora 等工具读取。

如果删除 KardLeaf，Markdown 文件会不会一起消失？

正文位于你选择的笔记库目录中，是否保留取决于 Android 卸载时该目录的位置和系统行为。重要笔记仍建议定期复制笔记库并设置备份，不要把“卸载应用”当成备份方式。

可以直接导入现有 Markdown 文件夹吗？

KardLeaf 的设计就是使用普通文件夹作为笔记库。你可以把现有 .md/.txt 文件放在授权目录中，再让 KardLeaf 读取和建立索引。

支持多个笔记库吗？

支持。当前功能包含新增、切换、重命名和管理多个笔记库，可将工作、学习、私人资料分开。

支持多级文件夹吗？

支持真实的多级目录结构，也支持展开/折叠、创建、重命名、移动、自定义排序和隐藏目录等管理能力。

电脑修改 Markdown 后，手机能识别吗？

可以。KardLeaf 可以重新读取外部变化并刷新索引，因此电脑端修改同一批 Markdown 文件后，手机端仍可继续使用。

换手机时怎么迁移 KardLeaf？

最重要的是迁移你的笔记库文件夹；如果还希望恢复应用设置或其他应用数据，可以结合 JSON 导出/导入与自动备份。同步用户也可以先把旧设备内容完整同步到远端，再让新设备拉取。

KardLeaf 支持导出吗？

正文天然就是可复制的 Markdown/TXT 文件；此外设置中还有应用数据 JSON 导出/导入与自动备份功能。详见 同步与备份。

归档和删除有什么区别？

归档用于把内容暂时移出日常视图但继续保留；“废弃/Trash”用于进入后续恢复或彻底清理流程。详见 归档、废弃与自动清理。

误改笔记后能恢复旧内容吗？

普通笔记提供历史版本列表、关键词搜索、版本比较和恢复能力，也可配置历史版本保留数量。详见 历史版本。

移动笔记后图片路径会不会失效？

KardLeaf 支持根目录和相对路径等图片模式，并包含移动文件时重写相对图片引用的处理。跨工具工作流中仍建议统一图片目录规则，避免不同编辑器各自改写路径。

Markdown 编辑与内容能力

关于编辑器、预览、格式、图片、附件和长文写作。

KardLeaf 支持哪些 Markdown 格式？

除标题、列表、引用、链接、代码等基础 Markdown 外，当前编辑链路还包含表格、数学公式、代码块、Mermaid、Admonition、HTML 块、图片、Wikilink 等扩展能力。详见 Markdown 编辑器。

可以边写边预览 Markdown 吗？

可以。KardLeaf 支持编辑与预览切换，并提供 CodeMirror 6 等编辑内核；你也可以设置打开笔记时优先进入编辑或预览。

为什么 KardLeaf 有多个编辑内核？

不同内核侧重不同体验：Native 系列强调原生输入/光标体验，CodeMirror 6 强调丰富 Markdown 交互与实时渲染。应用将文件管理与编辑内核分开，因此同一批 Markdown 文件可以切换不同编辑方式。

支持文章目录或大纲吗？

支持。编辑器侧边面板可以根据标题结构生成文章目录，用于长文快速定位。

支持在当前笔记内查找文字吗？

支持。编辑场景有文档内查找能力；跨笔记则使用全局搜索。

支持 [[双向链接]] 吗？

支持 Wikilink 形式的 [[笔记]] 链接，并可以进一步用于笔记关系图。详见 知识关系图。

支持 YAML / Front Matter 吗？

支持解析和显示 Front Matter 属性，YAML 中的标签也可进入索引并用于筛选，适合与 Obsidian 工作流配合。

支持 Markdown 表格吗？

支持。编辑器包含表格工具和表格渲染逻辑，可在 Markdown 文档中处理表格。

支持数学公式吗？

支持。预览链路包含 KaTeX/TeX 相关渲染，编辑工具栏也提供数学内容入口。

支持 Mermaid 图表吗？

支持。代码中包含 Mermaid 渲染、缓存和放大查看相关逻辑。

可以插入本地图片吗？

可以。支持本地图片引用、预览、首页首图缩略图、图库和图片查看。详见 图片与绘图。

支持画图或给图片做标注吗？

支持内置绘图，并提供画笔、荧光笔、橡皮、网格、撤销恢复及在原图上标注等能力。

支持音频、视频和普通附件吗？

支持在 Markdown Preview 中处理本地音频、视频和普通附件；音视频使用媒体控件和 Range 请求进行流式读取。详见 附件与媒体预览。

可以统计字数吗？

可以。属性面板可统计字符数、词数、行数、段落数等，并尽量排除 Front Matter 对正文统计的干扰。

编辑工具栏能自定义吗？

可以。当前代码定义了多种内置工具，并允许调整工具栏顺序、配置快捷文本、自定义符号和自定义功能项。

能快速插入常用模板或文本吗？

可以使用快捷文本、自定义符号和自定义功能项保存常用片段；速记与外部 URL Scheme 也适合快速套用固定记录流程。

分类、搜索与知识整理

适合笔记越来越多之后的查找、筛选、回顾和知识管理。

KardLeaf 支持全文搜索吗？

支持标题和正文搜索，并可组合大小写匹配、正则表达式、标签和文件夹条件。详见 搜索、日期与统计。

可以只搜标题、不搜正文吗？

可以。搜索选项把标题与正文范围分开控制，可以只查标题、只查正文或同时搜索。

搜索支持正则表达式吗？

支持，可与大小写、标签、文件夹等条件一起使用。

搜索结果能跳到命中的位置吗？

搜索结果模型包含命中片段和偏移信息，可用于显示附近正文并从结果跳转到命中位置。

支持标签吗？

支持正文 #标签 与 YAML 标签，并有标签管理和标签筛选能力。

支持收藏和置顶吗？

支持收藏、置顶、最近修改、速记、随机、日期、归档、废弃等多种首页/侧边栏视图。

支持批量移动或批量管理笔记吗？

支持多选后的移动、复制、合并、置顶、收藏、标签、归档、分享、隐私处理和删除等批量操作。

可以按日期查看笔记吗？

可以按今天、本周、月份等时间范围浏览笔记，并按修改时间组织结果。

有记录热力图吗？

侧边栏包含按天统计的热力图组件，用于观察一段时间内的记录活动；具体指标和展示算法可能随版本调整。

笔记很多时怎么更快找到内容？

建议组合使用文件夹、标签、标题/正文范围、正则、日期视图和收藏；大型知识库还可以拆分为多个笔记库，以减少单一入口的管理复杂度。

同步、多设备与备份

关于 WebDAV、S3、Syncthing、电脑协作和冲突处理。

KardLeaf 支持 WebDAV 同步吗？

支持应用内 WebDAV 同步管理器，并包含连接信息、同步预览、远端检查和实时同步相关配置。详见 WebDAV、S3 同步与自动备份。

KardLeaf 支持 S3 / OSS 一类对象存储吗？

支持兼容 S3 API 的对象存储，设置包含端点、Bucket、前缀和凭据，并可先测试连接和生成同步计划。

可以用 Syncthing 同步吗？

可以。由于正文是普通文件夹中的 Markdown/TXT，你可以让 Syncthing 负责同步整个笔记库，KardLeaf 负责本地读取和索引。

可以一边用 Obsidian，一边用 KardLeaf 吗？

可以。常见方式是电脑用 Obsidian 打开 Vault，Android 用 KardLeaf 打开同一结构，再通过 Syncthing、WebDAV、S3 或其他文件同步方式传递修改。详见 Obsidian 工作流。

KardLeaf 会强制把笔记上传到官方云吗？

不会强制。你可以只使用本地文件；如果需要多设备同步，可以自行选择 WebDAV、S3、Syncthing 或手动复制。

支持自动备份吗？

支持选择备份目标目录和备份周期；同时正文 Markdown/TXT 本身也可以直接复制保存。

两台设备同时修改同一篇笔记会怎样？

任何文件同步方案都可能产生冲突。KardLeaf 的同步实现包含差异计划和冲突选择，但更稳妥的方式仍是先让一端同步完成，再在另一端继续编辑。

离线写完后能等联网再同步吗？

可以先在本地继续写作，之后再执行你选择的同步方式。是否自动同步以及冲突处理取决于具体同步配置。

WebDAV 或 S3 连接失败应该检查什么？

先检查端点地址、账号/密钥、Bucket/路径、网络和服务端权限；优先使用应用中的连接测试或远端检查，再执行正式同步。

备份和同步是一回事吗？

不是。同步强调多端保持相近状态，错误删除也可能被同步；备份强调保留可恢复副本。重要数据建议同时保留独立备份。

隐私、安全与加密

关于隐私仓库、密码、生物识别以及网络功能的数据边界。

KardLeaf 有加密笔记功能吗？

有独立隐私仓库。隐私内容不是只在首页隐藏，而是进入加密存储流程，并在解锁后才把内容加载到内存。详见 隐私仓库。

隐私仓库使用什么加密方式？

当前公开实现使用 32 字节随机主密钥；密码 KDF 为基于 HMAC-SHA256 的 PBKDF2，默认 600,000 次；主密钥和正文使用 AES-GCM 相关流程，单篇笔记密钥还通过 HKDF-SHA256 派生。这里描述的是公开代码实现，不等同于第三方安全审计结论。

为什么需要 PBKDF2 这么多次迭代？

密码通常比随机密钥弱，KDF 的作用是把用户密码转换为更适合加密使用的密钥材料，同时提高暴力尝试每个候选密码的计算成本。

可以用指纹或生物识别解锁隐私笔记吗？

可以作为快捷解锁方式。首次密码成功后，可通过 Android Keystore 保护相关密钥，再结合生物识别流程使用。

忘记隐私密码还能找回吗？

从当前公开实现看，修改密码需要验证旧密码，并没有提供“绕过加密直接恢复明文”的设计。应把隐私密码视为重要密钥凭证，妥善保存，并保留独立备份；生物识别也不应当作永久密码恢复方案。

应用密码和隐私仓库密码是同一个东西吗？

不是完全同一层。应用级密码/指纹锁主要保护进入应用或界面；隐私仓库则涉及单独的加密存储和密钥流程。

普通本地笔记会自动上传吗？

普通本地编辑不要求上传。只有你主动使用云同步、网页读取、AI 等网络能力时，相应数据才需要与所配置的服务通信。

使用 AI 功能时笔记内容会发送到哪里？

当你主动调用 AI 时，相关文本会发送到你选择的 AI 服务端点。KardLeaf 支持 OpenAI 兼容接口、New API 和试用模式；第三方服务如何处理数据取决于对应服务商。详见 AI 写作助手。

AI API Key 怎么保存？

当前实现使用 Android Keystore 创建 AES 密钥，并以 AES/GCM 加密后保存用户配置的 API Key，而不是直接以普通明文 SharedPreferences 保存。

使用 WebDAV/S3 后数据是否仍然安全？

传输和远端存储安全取决于你的服务端、HTTPS/TLS、账号权限和服务商配置。KardLeaf 可以减少专有格式锁定，但不能替代云服务本身的安全配置。

任务、思维导图、网页、AI 与快速记录

针对“我需要某个具体能力”的用户。

KardLeaf 有独立任务清单吗？

有。任务可包含分组、父子任务、优先级、到期时间、提醒时间、重复规则、备注、手动排序和废弃状态。详见 任务与提醒。

Markdown 里的待办能进入任务视图吗？

可以选择把从笔记中扫描到的 Markdown 任务合并显示，并保留来源文件路径以便回到原笔记。

任务支持重复和提醒吗？

支持每天、每周、每月等重复规则，并支持弹窗或系统通知、铃声、振动、精确提醒权限检查和开机后的提醒恢复。

KardLeaf 有思维导图吗？

有。可以根据 Markdown 标题层级生成思维导图，并支持节点新增、重命名、删除、拖拽、撤销恢复、单向/双向布局和大纲定位。详见 Markdown 思维导图。

KardLeaf 有知识图谱或关系图吗？

有。可以读取 [[双向链接]] 生成笔记关系图，也可以手动创建自定义知识关系图。

支持每日笔记吗？

支持每日笔记目录和桌面小部件，以日期规则快速打开或创建当天笔记。详见 每日笔记。

有桌面小部件吗？

有笔记列表、任务清单、每日笔记和快速记录等 Widget，也包含 Android 快捷设置磁贴和固定快捷方式。详见 桌面小部件与快速记录。

能从其他 App 分享内容到 KardLeaf 吗？

可以通过 Android 分享接收流程进入速记，也可以使用快捷设置、Widget 或自定义 URL Scheme 快速新建。

支持网页剪藏或稍后读吗？

支持在线读取网页、提取正文并在 Preview 中阅读；决定编辑时再离线保存为本地 Markdown，还可选择下载网页图片。详见 网页笔记与外部调用。

网页离线后还能继续编辑吗？

可以。执行“离线并编辑”后，提取内容会进入普通本地 Markdown 工作流，可以继续使用搜索、标签、历史版本等能力。

KardLeaf 的 AI 能做什么？

当前公开实现包含摘要、润色、扩写、续写、缩短、纠错、翻译、解释、提取要点、提取待办、生成标题和自定义指令等操作。

可以使用自己的 OpenAI 兼容接口吗？

可以填写 Base URL、模型名称和可选 API Key，并在设置中测试连接。

能用 Tasker 或自动化脚本新建笔记吗？

可以。KardLeaf 提供 kardleaf://new URL Scheme，可传入标题、正文、网页地址、目录、置顶等参数，适合浏览器、Tasker、快捷方式和其他应用调用。

想快速记一条临时想法，有不用先找文件夹的方法吗？

可以使用速记、首页快速新建、Quick Memo 快捷设置磁贴、桌面 Widget、固定快捷方式或 Android 分享入口。详见 速记与快速新建。

常见问题与故障排查

遇到异常时先从这些高频原因开始检查。

为什么安装 APK 后打不开或被系统拦截？

先确认 Android 版本满足要求，并检查系统是否阻止未知来源安装、APK 是否完整、是否来自官方 Release。若仍异常，可到 GitHub Issues 提交设备型号、Android 版本和错误现象。

为什么应用看不到我刚在电脑修改的 Markdown？

确认同步工具已经把文件真正写到手机授权目录，然后在 KardLeaf 中触发外部文件刷新/重新索引。若文件仍不可见，再检查扩展名、目录授权和隐藏目录规则。

为什么移动笔记后图片不显示？

通常与图片路径有关。检查当前使用的是根目录还是相对路径模式、图片文件是否一起移动、Markdown 引用是否仍指向有效位置。跨 Obsidian/其他编辑器时最好统一图片目录策略。

为什么任务提醒没有响？

检查 Android 通知权限、精确闹钟权限、电池优化/后台限制、任务提醒时间，以及任务是否启用了铃声/振动。设备重启后应用也有提醒恢复逻辑，但厂商后台限制仍可能影响调度。

为什么 WebDAV 同步失败？

先用连接/远端检查验证服务器地址、用户名密码、路径和证书，再检查服务端是否允许需要的文件操作。不要一上来反复执行完整同步。

为什么 S3 连接测试失败？

检查 Endpoint、Bucket、前缀、Access Key/Secret、区域/签名兼容性以及网络。不同 S3 兼容服务对条件写入等细节可能不同。

为什么网页无法提取正文？

网页入口要求有效的 HTTP/HTTPS 地址；某些需要登录、强脚本渲染、反爬或结构特殊的网站可能无法正常读取。可以先在浏览器确认页面可访问，再尝试导入。

为什么网页离线后某些图片缺失？

离线时需要开启下载网页图片；即使开启，单张图片仍可能因防盗链、权限、失效 URL 或网络问题下载失败。正文导入不会要求所有图片必须成功。

为什么本地音频或视频无法播放？

先确认文件仍存在、应用有目录访问权限、附件链接有效且 MIME 类型可识别。普通不支持直接播放的附件会保留为链接交给系统处理。

笔记库很大时怎样减少查找和管理压力？

可以把工作/学习/私人内容拆成多个笔记库，利用标签、文件夹、日期和搜索条件缩小范围，并避免多个设备同时大规模改写同一批文件。实际性能仍取决于设备、文件数量和单篇内容规模。

同步冲突时应该选哪一个版本？

先比较本地与远端的修改时间和内容，优先保留你确认更新的一份；重要内容先复制出独立备份再处理冲突。不要在不确定时直接批量覆盖。

遇到 Bug 应该提供哪些信息？

建议提供 KardLeaf 版本、Android 版本、设备型号、可复现步骤、期望结果、实际结果，以及必要的截图或日志；涉及隐私笔记时不要上传真实密钥或敏感正文。

Obsidian、开放工作流与开发者

关于与其他工具协作、项目源码和二次开发。

KardLeaf 和 Obsidian 是什么关系？

KardLeaf 不是 Obsidian 官方客户端，也不承诺实现 Obsidian 全部插件生态。它更像 Android 端的开放 Markdown 工具，重点兼容普通 Markdown、目录、标签、YAML、Wikilink 和文件工作流。

能直接打开 Obsidian Vault 吗？

在 Android 文件权限允许的前提下，可以把普通 Markdown Vault 目录作为笔记库使用。复杂插件生成的数据或 Obsidian 私有扩展不保证完全兼容。

为什么说 KardLeaf 不容易被“格式锁定”？

因为正文主要是普通 Markdown/TXT 文件，目录也是实际文件夹结构。即使以后不用 KardLeaf，这些文件仍可被大量文本编辑器和 Markdown 工具读取。

KardLeaf 能代替 Obsidian 桌面版吗？

定位不同。KardLeaf 更适合作为 Android 本地 Markdown/Obsidian 工作流的移动补充；如果依赖大量桌面插件、复杂脚本或桌面布局，仍建议保留 Obsidian 桌面端。

KardLeaf 能和 Typora、VS Code 一起用吗？

可以，只要它们操作的是同一批 Markdown 文件，并通过你选择的同步方式保持文件一致。

KardLeaf 的源码在哪里？

源码仓库：github.com/waikr/KardLeaf。

我可以自己编译 KardLeaf 吗？

可以。仓库 README 给出的开发环境包括 Android Studio、JDK 17、Android 设备或模拟器，构建可使用 Gradle。

我可以基于 KardLeaf 修改或二次开发吗？

可以在 Apache License 2.0 允许的范围内进行修改与分发，同时需要遵守许可证中的相关要求。

如何提交问题或建议？

可以前往 GitHub Issues。功能建议最好说明使用场景、当前痛点和期望交互，而不仅是功能名称。

哪里能看到 KardLeaf 的完整功能列表？

可以查看 完整功能总览，并进入编辑器、搜索、任务、思维导图、同步、隐私、AI、网页笔记等独立详情页。

没有找到你的问题？
